# CoreTCM 分析后视觉核查记录

完成日期：2026-09-25。使用 180 条合成处方、21 味药物及三组临床字段，无真实病例。

## 核查范围

- 应用实际页面：频次柱状图、关联规则散点图及有向网络；Ward 热图、树状图、药物簇柱状图；K-means 肘部图及热图；社区网络和四性、五味、归经雷达图；核心配伍分类、散点图；病位、病性、证型热图及核心配伍临床关联表。
- 使用相同服务器模块生成的独立结果页：四项指标分布、药对比较散点图、聚类—社区流向图、候选药物排序图，并检查中英文版本。
- 全流程回归：M0 清洗 → M1 特征提取 → M2 规则及聚类 → M3 社区 → M4 分类 → M5 关联、分类器链训练和推荐 → M6 比较。得到 3 个社区、63 个共有药对、21 味候选药物。
- 已验证中英文往返切换；原始药名和临床值保持不变。

## 本轮修复

- 补齐动态图题、图例、状态、分类、模型状态及表头的中文。
- 修复 Ward 树状图药物标签缺失。
- 减少雷达图刻度重叠；推荐详情改为悬停显示，宽结果表增加横向滚动。
- 修复 disease_nature 字段识别、手动选列命名空间、直接读取临床列时的错误空结果提示及证型数量统计。
- 修复单字临床特征被过滤的问题，保留“肝、脾、肺、热”等有效值，覆盖关联统计及模型输入。
- 推荐增强得分使用数值显示，避免将其误标为概率百分比。

## 验证与复现

- `tests/test_i18n.js`：客户端翻译、动态更新、往返切换和原始值保护。
- `tests/test_i18n.R`：字典、缺失键回退、格式化及数据保护。
- `tests/test_clinical_visual_regressions.R`：临床列识别、证型数量及单字特征回归。
- `tests/prepare_visual_report.R`：调用真实模块事件处理函数运行完整流程，验证表格及双语图表渲染，生成 `tests/visual-report/index.html`。
- 所有 R 源文件语法解析通过。

内置浏览器的文件选择器与 Shiny 实时连接不稳定，因此采用独立测试入口加载合成数据，后续比较、推荐结果保存为独立 HTML 图表完成视觉核查。未将文件上传控件的浏览器兼容性或所有参数组合列为已验证。合成数据训练时存在拟合收敛警告，本轮仅验证流程和界面，不评价模型临床效能。
