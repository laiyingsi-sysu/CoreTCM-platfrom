# 数据说明

## 内置字典

- `data/中药标准化字典.xlsx`：第一张表含 623 条药名映射，字段为“原始名称”“标准名称”。
- `data/药物归经、五味、功效属性.xlsx`：第一张表含 474 条药性记录，字段为“药物名称”“四性”“五味”“归经”。
  文件名包含“功效”，实际表中没有独立的功效列；另有两张空工作表。

两份字典从现有平台复制，保留原文件名以兼容应用路径；
发布副本仅移除了 Excel 作者和最后修改者元数据，表格、样式和其他工作簿内容保持原样。
原项目中未找到明确的数据来源或许可声明，发布者应补充相应信息。

## 小型导入示例和模板

`data/example_formula_only.csv` 与 `data/example_formula_clinical.csv` 各含 7 条示例，
用于测试分隔符、炮制前缀、剂量保留和临床字段识别。
`template_*.csv` 中的表头演示自定义映射所需字段；不同上传控件支持的文件格式以界面为准。

## 水肿模拟数据

`examples/synthetic/edema_sim_sample_1000.csv` 为现有随机生成数据的 1,000 条样本，
对应脚本 `generate_edema_data.R` 使用 `set.seed(20260814)`，
以 7 个方剂组合为种子，加入合方、加减药、剂量变化和临床字段缺失。
其中 97 条样本的证型及相关标准化字段为空，CSV 用 `NA` 表示，供流程测试使用。
`patient_id` 是随机生成的标签，脚本未保证其唯一性。

| 字段 | 含义 |
| --- | --- |
| `patient_id` | 模拟记录标签，无真实患者对应关系 |
| `herb_medicine` | 以半角分号分隔的药名，上传时选为处方列 |
| `证型` | 含别写和缺失值的模拟原始证型 |
| `标准证型` | 生成器设定的标准证型 |
| `病位`、`病性` | 模拟病位和病性，可含多个词条 |
| `dosage` | 与药名顺序对应、以分号分隔的模拟剂量数值 |
| `dosage_form` | 模拟剂型 |
| `年龄`、`性别` | 随机生成的人口学字段 |

`dosage` 与 `herb_medicine` 分列保存。当前清洗功能保留的是处方字符串中原有的剂量表达，
不会自动把这两个字段重新拼接。

同目录的两份映射 CSV 用于证型标准化与病位/病性查表。
项目中的真实研究数据表、论文文稿与完整的 20,000 条模拟 CSV 不在本发布副本内。

## 重新生成

在 R 中先进入模拟数据目录，再运行生成脚本：

```r
setwd("examples/synthetic")
source("generate_edema_data.R", encoding = "UTF-8")
```

脚本会在当前目录写出 20,000 条完整模拟数据、1,000 条样本及两份映射表，
并覆盖同名文件；完整模拟数据已加入 `.gitignore`。
随机种子固定，但跨 R 版本的生成一致性应以实际复现核查为准。
本次在 R 4.4.2 上复现后，样本和两份映射表与发布文件逐字节相同。
发布副本移除了原脚本开头会影响 R 解析的 UTF-8 BOM，生成逻辑保持原样。
